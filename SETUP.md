# Development Set-up
## Prerequisites
* YOLOv5
* Anaconda (optional)
* Python 3.5
* face images
* Desktop
* Visual Studio Code
## Instructions
1. Install YOLOv5 from [link](https://docs.ultralytics.com/yolov5/quickstart_tutorial/)
2. Install Python 3.5 from [link](https://www.python.org/downloads/windows/)
3. Navigate to the `app` folder
4. Run the following command to use the program:
```
python app.py
```
